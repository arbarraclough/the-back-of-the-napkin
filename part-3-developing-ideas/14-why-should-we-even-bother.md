# 14. Why Should We Even Bother?

> **"Framework 6: To show a why problem, use a multiple-variable plot."**

## Why Spend the Money?

Often, understanding the _why_ involves seeing multiple pieces of information tied together in a single picture.

> "After we'd seen _who_, _what_, _how much_, _where_, _when_, and _how_, we saw reason(s) emerge. The longer we watched everything interact and focused our attention upon cause and effect, the more we began to understand _why_ things worked the way they did. In order to show others the reasons and to begin to make predicitons about how things will work again, we create multiple-variable plots."

### Multiple-Variable Plots: General Rules of Thumb

1. **Multiple-variable plots aren't hard to make, but they do require patience, practice, and above all, a point.**

    A well-thought-through and clearly drawn multiple-variable plot is the most powerful and insightful picture we can create, however, there's no simple explanation on how to create one.

    1. Start with a simple x-y plot using any two qualitative variables that you have data for as the coordinate axes.
    2. Plot any quantitative variable you have data for in the middle using an appropriately sized bubble, starting with just one point in time.
    3. Add another set of bubbles showing the same quantitative variable at another time.
    4. Repeat.

2. **Medium-thick soup is best.**

    Multiple-variable plots create a scale model of an entire business universe/problem.

    Identify a limited number of aspects that _may_ have great influence on one another and isolate.

    Too few variables and you end up with a bar chart.

    Too many and you're back to the original problem of too much to look at.

    The only way to know the "right" number is to start plotting and seeing what ideas emerge.

3. **Anything can be mapped to anything else, but...**

    Multiple-variable plots make it too easy to "discover" connections between variables that have nothing to do with each other. Remember: correlation (the appearance of trends between variables) is not the same as causation (the direct impact of one variable on another).

## Case Study: SAX Inc.

When comparing the top companies in the sector, you can use a multiple-variable plot to show the revenue-per-company between years.

![Revenue Per Company](images/revenue-per-company.png)

However, there are more variables we could add to show better understanding, e.g., the standards each company follows.

![Revenue Per Company Per Standard](images/revenue-per-company-per-standard.png)

Finally, we can add _another_ variable to show a deeper understanding, e.g., _why_ the standard the companies follow matters.

![Revenue Per Company Per Standard And Why](images/revenue-per-company-per-standard-and-why.png)

With this final graph, we're able to see multiple pieces of important information, including:

- Each company's current and projected income between now and next year,
- What kind of standard each company's software follows,
- Consumer reasons for _why_ some of these changes are happening.

This is the kind of information executives need to make decisions.
